## Intro
This is my personal theme set that is forked off of themes that I enjoy with some tweaked colors. Due to which, these themes are subject to change as I play around with them.

## Name
The name is supposed to invoke the idea of a zen garden as in an editor is the garden and the code is the gravel you rake. Being a fork of everforest/evergarden I kept the "ever" in the name for fun. The direct translation of the word for zen gardens is "dry mountains and water" which is where the word "mountain" came from. Additionally, it indirectly references Mount Everest which I though was pretty fun.
